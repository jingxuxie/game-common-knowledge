# Reproducibility Notes

## Claims and evidence

- Every analytic construction is represented by a benchmark generator and a unit test.
- The joint feature-policy MILP is compared with exhaustive feature-set optimization on small games.
- Correlated-certificate tests exhaustively verify diminishing returns on small generated instances and check the `1-1/e` cardinality guarantee.
- All tables and figures are regenerated by `make experiments`.
- Checked-in CSV and JSON files contain the raw aggregate outputs used by the manuscript.

## Compute

No GPU is used. The full test and experiment suite is intended for a laptop CPU and normally finishes in a few minutes on a recent workstation. Exact runtime values depend on the HiGHS/SciPy build and hardware.

## Randomness

All random generators use explicit NumPy seeds in `experiments/run_all.py` and `experiments/run_correlated_certificates.py`. The experiment scripts overwrite generated outputs deterministically, apart from machine-dependent wall-clock timings.

## Software

The tested implementation uses Python 3.11/3.13, NumPy, SciPy with `scipy.optimize.milp`, Matplotlib, pandas, and pytest. Exact version lower bounds are recorded in `requirements.txt` and `pyproject.toml`.

## Artifacts

- Source: `src/common_knowledge/`
- Tests: `tests/`
- Experiment drivers: `experiments/run_all.py`, `experiments/run_correlated_certificates.py`
- Result validators: `scripts/validate_results.py`, `scripts/validate_correlated_results.py`
- Raw results: `results/`
- Vector figures: `figures/*.pdf`
- Manuscript: `paper/`

## AAAI formatting

`paper/main.tex` is the anonymous AAAI-27 entry point. To avoid accidentally substituting an unofficial or modified style, the repository does not vendor the author kit. Copy the official unmodified `aaai2027.sty` and `aaai2027.bst` into `paper/` before running `make aaai`.
