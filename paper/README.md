# Manuscript build notes

The repository provides two manuscript entry points:

- `preprint.tex` generates the nine-page review draft. Pages 1--7 contain the
  technical paper and pages 8--9 contain references. GitHub Actions rebuilds
  the PDF from source and publishes the exact compiled files in the
  `common-knowledge-artifact` workflow artifact.
- `main.tex` is the anonymous AAAI-27 entry point. It must be compiled with the
  **official, unmodified** `aaai2027.sty` and `aaai2027.bst` from the current
  AAAI-27 Author Kit.

To regenerate both experiment suites and build the preprint and supplement from
repository root:

```bash
make paper
```

To build the official-format source after copying the two Author Kit files into
this directory:

```bash
make aaai
```

Do not substitute a style file copied from an unrelated repository for the
submission build. Immediately before submission, compare the downloaded style
and bibliography files with the current Author Kit, compile using PDFLaTeX, and
complete the remaining checks in `notes/submission-checklist.md`.

The manuscript numbers are generated by `experiments/run_all.py` and
`experiments/run_correlated_certificates.py`. Run their consistency audits with:

```bash
make validate
```
